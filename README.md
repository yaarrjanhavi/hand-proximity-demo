
(NumPy will be installed automatically as a dependency.)

## Usage

1. Clone or download this repository.
2. Install dependencies as shown above.
3. Run:
```
python main.py
```

4. Move your hand in front of the webcam and towards the blue rectangle:
   - Green text: **SAFE**
   - Yellow text: **WARNING**
   - Red text + **"DANGER DANGER"**: **DANGER**

## Notes

- You may need to adjust the HSV skin-color range and distance thresholds depending on lighting and skin tone.
- The rectangle position and size can be changed in the code to match your preference.
